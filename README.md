## Features

- Add, delete, and reorder tasks
- React hooks

## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/TodolistApp_React.git
cd TodolistApp_React
npm install
npm run dev     # or `npm start`, depending on the setup
```
